## Trigger

This contract activates only when the Human Researcher supplies a future author reply or another admissible primary-source artifact. It does not send contact, fetch data, run code, or apply a fallback while waiting.

## Required sequence after a reply

1. Preserve the supplied reply as original evidence or a faithful, date-stamped evidence summary with source context. Do not discard the prior ambiguity history.
2. Run `PRIMARY_SOURCE_RECONCILIATION_AUDIT` before changing code, protocol, architecture, or any gate.
3. Map each author statement explicitly to affected Class C/D blockers, `PAPER_AMBIGUITY_REGISTER.md`, `PAPER_MISSING_PARAMETER_REGISTER.md`, the Phase 8 shortlist, and dependent Phase 2–9 contracts.
4. Mark each field independently as `RESOLVED_BY_PRIMARY_SOURCE`, `PARTIALLY_RESOLVED`, `CONTRADICTED_BY_PRIMARY_SOURCE`, or `STILL_UNRESOLVED`; retain the author evidence locator.
5. Identify whether the clarification invalidates a prior Human fallback, structural interface, sample manifest, or planned experiment. Record a plan-change requirement before altering any affected active contract.
6. Reassess `FUSION_ERROR_DEFINITION`, `FUSION_RATIO_DEFINITION`, and inference-time availability separately. A reply that does not establish leakage-free availability must not reopen the fusion numerical pipeline.
7. Reopen the Phase 9 gate only if the reconciliation audit establishes that all remaining Class C/D prerequisites for the requested numerical tier are resolved or separately Human-authorized under the Tier 2 rules.
